# Smart Restaurant

Smart Restaurant is a restaurant ordering and management web application.

## Features
- Restaurant food menu
- Shopping cart
- Customer order placement
- Admin dashboard
- Order status management
- Sales overview
- Node.js and Express backend
- SQLite database

## Requirements
- Node.js 20 or later
- npm

## Installation

1. Download or clone this repository.
2. Open a terminal in the project directory.
3. Install dependencies:

```bash
npm install
```

4. Configure the required environment variables:
    - SESSION_SECRET Atik1234954&(8)0
   - ADMIN_USERNAMEAtik12349594&(8)0
   - ADMIN_PASSWORDAtik1034954&(10)0

5. Start the application:

```bash
npm start
```
