Smart Restaurant — Vibe96 Buyer-ready update (v1.0.2)

এই সংস্করণে:
- Login screen-এ One-click Admin Demo Login রাখা হয়েছে।
- ডেটাবেস প্রথমবার তৈরি হলে read-only demo admin স্বয়ংক্রিয়ভাবে তৈরি হয়।
- Demo dashboard-এ আসল ডেটা থাকলে পরিচয় গোপন করে দেখায়; অর্ডার না থাকলে response-only sample orders দেখায়। Sample order কখনো database-এ লেখা হয় না।
- Demo account দিয়ে menu/order পরিবর্তন server-side-এ নিষিদ্ধ।
- Home, Cart, Checkout এবং Admin Dashboard আলাদা view হিসেবে রাখা হয়েছে।
- Premium restaurant-inspired design এবং dish-specific real food photography যোগ করা হয়েছে।
- আসল admin credentials শুধু Render environment variables-এ রাখতে হবে।

Render environment variables (আগেরগুলো অপরিবর্তিত রাখুন):
SESSION_SECRET (কমপক্ষে 32 characters)
ADMIN_USERNAME
ADMIN_PASSWORD (কমপক্ষে 12 characters)
NODE_ENV=production

DEMO_ADMIN_USERNAME / DEMO_ADMIN_PASSWORD আর প্রয়োজন নেই।
Build Command: npm install
Start Command: npm start
