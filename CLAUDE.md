# Smart Restaurant Project Guide

## Project Overview
Smart Restaurant is a restaurant management and online ordering application.

## Technology
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Database: SQLite with better-sqlite3

## Development Instructions
- Preserve the existing project structure.
- Keep the interface responsive and accessible.
- Validate customer input on the server.
- Protect administrative routes with server-side authentication.
- Store secrets in environment variables.
- Never commit passwords or secret keys to GitHub.
- Test application functionality after making changes.

## Deployment
Install dependencies using `npm install` and start the application using `npm start`, after configuring the required environment variables.
